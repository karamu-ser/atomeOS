# Roadmap AtomeOS

## v0.1
- Base Ubuntu customisée avec Cubic.
- Overlay système pour le branding AtomeOS.
- Centre Atome en Bash/Zenity.
- Assistant local via Ollama et `llama3.2:1b`.
- Assistant vocal local avec mot-clé `atomeos`.
- Commandes terminal `ask`, `explain`, `atome-ai`.
- Premier démarrage guidé.
- Profils `lightweight`, `student`, `creator`, `developer`.

## v0.2
- Centre Atome en application native plus propre.
- Gestion des thèmes et wallpapers depuis l'interface.
- Installation optionnelle de VS Code plus robuste avec dépôt officiel ou paquet `.deb`.
- Meilleure gestion du téléchargement des modèles IA.
- Page de statut plus complète : réseau, batterie, services, espace disque.

## v0.3
- Profils utilisateur personnalisables.
- Assistant capable de lire des fichiers avec confirmation utilisateur.
- Documentation de build Cubic pas à pas.
- Tests automatisés des scripts de l'overlay.
