# AtomeOS

AtomeOS est une distribution Linux moderne basée sur Ubuntu, conçue avec Cubic.

## Objectif
Créer une ISO personnalisée élégante, simple, rapide et prête pour évoluer vers un système plus complet.

## Première version
La v0.1 vise à :
- personnaliser l’apparence
- ajouter quelques applications utiles
- préparer une base propre et reproductible
- générer une première ISO fonctionnelle

## Stack actuelle
- Base : Ubuntu
- Outil de personnalisation : Cubic
- Structure : overlay + scripts + branding
